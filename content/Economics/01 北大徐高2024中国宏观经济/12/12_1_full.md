
# **第一章：导论：理解中国金融运行的底层逻辑**

今天我们将进入本次课程的正题。我今天要讲的问题，实际上是对过去几讲内容的一个总结。在我们进入金融学和金融体系的探讨后，过去几讲我们是从货币的探讨路径这一角度切入，去分析中国金融体系中货币的运行情况，其中也包括上一讲谈到的人民币汇率问题。这都是一个循序渐进的过程。

当然，我们前几讲更多的是在描述现象，尽管描述得比较细致，但没有过多地去阐述现象背后的道理。因此，今天我们就要进行一个总结，旨在理解为什么中国在过去，尤其是自全球四大危机以来的这十几年里，国内的金融运行呈现出如此一个状态。

我认为这背后存在一个核心逻辑。这个逻辑正是我们进入金融学部分时就强调的：不能只就金融谈金融，那样是无法真正理解经济问题的，必须要把实体经济与金融要素结合起来进行分析。所以，我们今天就要将实体与金融结合，来理解中国金融运行的内在逻辑。

# **第二章：宏观框架：储蓄的两个去向**

我们先看一个整体框架。在此前的课程中，我们介绍过国民收入恒等式。简单来说，从支出法定义GDP的公式为：

$GDP = 消费 + 投资 + 净出口$。

对这个公式进行变形，就可以得到我们下方的等式：

$储蓄 = 投资 + 经常账户$

在之前的视频中，当讲解全球失衡问题时，我们曾将其表述为“经常账户 = 储蓄 - 投资”。当时我们解读为，一个国家经常账户所反映的外部失衡，与其内部失衡是相互关联的。一个拥有经常账户顺差的国家，意味着它正通过经常账户，将其国内无法完全利用的富余储蓄输出到国外。

今天，我们换一个角度来解读这个等式，将经常账户移到等式的另一边，得到：

$储蓄 = 投资 + 经常账户$

这个公式清晰地反映了国内储蓄的两个主要用途：其一，用于国内投资；其二，通过经常账户顺差的形式借给外国人。

回顾我们的课程内容，第八讲到第十一讲的核心，其实就是在梳理这个大框架下的金融逻辑。其中，第八讲到第十讲主要阐述了储蓄如何通过国内金融体系向投资转化。而第十一讲，我们讲开放经济的货币政策，实际上是在探讨储蓄如何向经常账户转移，这其中就涉及贸易顺差、外汇占款、人为干预的汇率等问题。

因此，金融的本质是什么？金融的本质就是储蓄的转移。我在第九讲（也可能是第八讲）中，通过一个简单的模型向大家展示了银行“吸储放贷”过程背后储蓄转移的实质。既然金融是储蓄的转移，那么在分析时，就必须将实体经济的基本状况纳入框架之内。

# **第三章：实体经济背景：高储蓄的成因**

我们之前讲过中国的实体经济基本状况。左边的图表清晰地显示，中国的储蓄行为与其他国家，特别是其他发展中国家相比，有其独特性。中国的企业储蓄和居民储蓄都非常高，其背后的原因在于企业部门与居民部门之间的割裂，导致了中国成为一个消费不足、储蓄过剩的经济体。

右边的图表也是之前展示过的，它从居民消费者的角度描绘了这一状况。蓝色的虚线曲线代表了企业本可以为消费者提供的分红边界。但由于一部分企业股权并非由居民持有，这部分股权就不会向居民提供分红。因此，居民真正能够获得的分红边界，实际上是蓝色的实线部分。剩下的那部分未被分红的利润，就刚性地转化为了储蓄，这进一步导致整个社会的利率水平受到压制。如图所示，市场本来的均衡切线（其斜率代表利率）位置较高，而现实中的利率则被压低了。

所以，中国的基本现实状况是，由收入分配结构所导致的储蓄过剩，并且这种储蓄过剩在金融体系中形成了规模巨大的储蓄存款，等待向投资转化。

# **第四章：金融体系的结构性特征**

金融的核心功能是连接储蓄与投资。然而，不同国家的储蓄与投资状况差异巨大，这也决定了各国将储蓄转化为投资的金融体系在结构与特性上会截然不同。金融体系并非放之四海而皆准，国与国之间的差异可能非常大。

我们来看一组数据。这是2022年中国、美国、日本、德国四个大国储蓄和投资占各自国家GDP的比例。可以看到，中国的储蓄与投资占比是最高的，并且储蓄高于投资，这解释了中国为何拥有经常账户顺差。美国的储蓄则低于投资，而日本和德国介于两者之间。

接下来，我们观察这四个国家的金融结构指标。第一个图是广义货币（$M_2$）与GDP的比例。中国的$M_2$/GDP比率持续上升，而日本的比率同样在上升，甚至水平比中国更高。相比之下，美国和德国则明显低于日本和中国。这对应着货币创造的模式，中国与日本的银行信用创造相对更多。

再看第二个图，股市市值与GDP的比重。美国无疑是最高的，日本的股市市值也较大，而德国和中国的股市市值与GDP之比则相对较低。

将这两个图结合起来看，可以发现中国和美国的融资结构存在巨大差异（当然日本与中国也有差别，但中美差异最为显著）。中国是一个以银行信用创造（广义货币）为主的经济体。广义货币的产生，本质上是银行向实体经济投放的信用，这可以通过银行贷款，也可以通过银行购买实体经济发行的债券来完成。中国的这种通过银行产生的信用规模较大，但通过股票市场进行的融资则相对较少。

而美国，其融资结构中，股市融资的占比远远大于中国。中国的情况则比较极端，在社会融资规模（社融）的构成中，根据近年的数据，银行贷款约占60%，债券融资约占37%-38%（债券融资既包含企业债，也包含政府债）。最后，股票融资在社融中的占比，过去八年平均大约为3%，而2024年截至目前可能只有0.7%。

问题是，这种融资结构为何会形成？是偶然形成的，还是背后有其必然的道理？我个人认为，我们这种以债权融资为主导的结构，与中国实体经济的失衡有着密切的联系。

# **第五章：债权主导融资结构的根源：为何股权融资“做不大”？**

接下来，我们将探讨中国这种债权融资主导的结构背后的逻辑。我的核心观点是：**我们这种融资结构，根植于消费不足的失恒实体经济结构。**

## **5.1 股权价值的来源：股东话语权**

首先，我们看一个基本事实。正如上半学期在讲解实体经济失衡时提到的，中国是一个企业向居民分红极少的经济体。根据国家统计局发布的资金流量表数据（该数据较为全面地涵盖了中国经济），金融企业和非金融企业的可支配收入（即利润）在分红后，约占GDP比重的近25%。而它们向外的总分红（图中虚线所示）大约占GDP的3%多一点。在这3%多的总分红中，真正流向居民部门的部分，仅占GDP的0.4%，这是一个非常小的比例。

与之形成鲜明对比的是美国。根据美国的国民经济核算数据，美国企业分红前的利润占GDP的比重大约只有12%。（相比之下，中国企业分红前的利润占比约为28%）。然而，美国企业向外的分红（包含股票回购）规模巨大，近年占GDP的比重约7%，且其分红的绝大部分都流向了居民部门。可以说，美国居民所得的企业分红几乎等于美国企业的总分红。但在中国，企业分红中流向居民的部分，仅占总分红的百分之十几。这种宏观数据上的差异是极其显著的。

我们曾解释过，这背后的原因是所有制结构的不同。分红流向股东，而中国的普通百姓虽然名义上是国有企业的“全民所有者”，但实际上并不直接持有国有企业的股份，因此分红也无法直接流到普通百姓手中。根据更新到2021年的数据显示，中国企业部门的总分红中，流向居民部门的比例仅为12%。分红的大头流向了企业（非金融企业）和政府，当然也有一部分流向了金融企业。

那么，这个事实意味着什么？它直接关系到股票融资为什么在中国规模做不大的问题。

资产的定义是“能够带来未来经济利益的资源”。那么，股票的价值来自哪里？学过金融学的都清楚，股票的价值来自于其未来的分红。我的问题是，股票为什么会向你分红？或者说，作为股东，你凭什么可以预期未来能获得分红？

股票与债券不同。在债券融资中，本金和利息的偿付是明确写入合同的。如果融资方不偿还本息，就构成违约，可以诉诸法律。但在普通股的“合同”中，并不承诺股息和股本的偿还。（优先股会承诺固定股息，但它更像一种债权融资，因此优先股股东通常没有投票权）。

那么，你作为普通股股东，之所以能够预期分红，是因为你相信，作为股东，你拥有了企业的一部分，对企业的经营拥有话语权。当你认为企业需要分红时，你可以要求企业分红。因此，**股票长期投资价值的根本来源，在于股东对上市公司的支配力。**

反之，如果告诉你，虽然你买了一张股票，但你对上市公司没有任何话语权，公司可以完全不听你的要求，那么你就无法对分红形成稳定预期。在这种情况下，这张股票对你而言就只是一张废纸。

## **5.2 股东决策与中国股市的现实**

如果你学过股票估值，一定知道一个非常流行的模型叫股利贴现模型（DDM, Dividend Discount Model）。它认为，股票的现值（$S_0$）等于其未来所有分红的贴现值总和。

$$S_0 = \sum_{t=1}^{\infty} \frac{E(D_t)}{(1+r)^t}$$

但是，深究一步，我们如何能预期到未来的分红（$D_t$）呢？答案依然是股东对上市公司的支配力。

那么，股东在什么情况下会要求企业分红呢？一个直接的场景是：当上市公司的投资回报率低于市场的平均回报率时。比如，我把钱存银行能获得5%的利息，而我投资的这家上市公司回报率只有3%，作为理性的股东，我肯定会要求它停止投资，把钱分给我，因为我拿着钱存银行都比它投资强。

但如果企业的投资回报率并不低于市场回报率呢？比如，市场回报率是2%，企业回报率是3%。这时候股东还会要求分红吗？答案是：**未必，这取决于股东是谁。**

* **如果股东是消费者：** 对消费者而言，投资永远存在一个“机会成本”，那就是“现在就消费掉所能获得的效用”。消费者的“时间偏好”可能会很高。即使企业3%的回报率高于市场2%的回报率，但对于一个不耐心、或者当前消费水平很低（因而边际效用很高）的消费者来说，3%的回报率依然太低，他宁愿企业把钱分给他用于当期消费。
* **如果股东不以消费为目的（例如国家或其他企业）：** 对于这类股东，其投资的唯一机会成本就是在市场上能获得的回报率。因此，只要该上市公司的投资回报率不低于市场回报率，这类股东就不会要求分红。

现在，我们把这个逻辑应用到中国。假设绝大多数企业的股东都是这种“不在乎消费”的股东。结果会怎样？由于大家都不在乎消费，都会进行大量投资，这将导致全社会的投资回报率被压得很低。当全社会的回报率都处于低位时，即使某个上市公司的回报率已经很低了，但只要不比市场平均水平更低，它的非消费型股东就不会要求它分红。

这种情况，若以消费者的时间偏好为评价标准，实际上就构成了**过度投资**和**过少分红**。

我们国家的企业部门，其主要股东并非普通消费者。大量存在的国有企业自不必说，即便是民营企业，也普遍存在“一股独大”的现象，而这些大股东往往更在乎打造“百年老店”或“伟大的企业”，而非当期消费。

在这种不为消费者所控股的企业中，你我这样的普通人最多只能成为小股东。作为小股东，我们对企业缺乏支配力。从我们的消费者时间偏好来看，企业的投资回报率可能已经太低（比如只有3%，而我们要求的最低回报是5%）。如果我们是控股股东，我们会要求企业减少投资、增加分红。但现实是，我们说了不算。控股股东（比如国家）认为3%的回报率已经可以接受，无需分红。

在这种情况下，作为小股东，我们无法预期能从这些企业获得足够的分红。既然如此，这些股票对我们来说就缺乏长期投资价值。那么要在股市挣钱，唯一的出路是什么？**只能是依靠炒作价差来获利。**

这就是为什么中国的A股市场投机炒作之风如此盛行，并非因为中国人天性爱炒作，而是市场环境使然，不炒作就无法获得收益。久而久之，那些不爱炒作、寻求长期稳定回报的投资者就不会进入这个市场。

一个以炒作为主的市场，其融资承受能力必然是有限的。因为用于炒作的标的不能太多，一旦供给过量，就炒不起来了。一个典型的例子就是“新三板”。它在建立之初是真正意义上的注册制，上市无需监管审批，满足信息披露等硬性条件即可。结果，最多时一年上市了一万多家企业，股票供给泛滥，大家发现根本没法炒，最终导致炒家也离场，新三板市场流动性枯竭，变得非常沉寂。

因此，我们的逻辑链条是：**实体经济中所有制结构导致的消费不足、储蓄过剩 -> 股票市场因企业分红预期缺失而缺乏长期投资价值 -> 投资者被迫通过炒作价差获利 -> 炒作市场无法承受大规模融资 -> 股市融资功能受限 -> 大量储蓄只能通过债权形式完成向投资的转化。**

这就是为什么中国的融资结构必然是以债权为主导的，这与我们的实体经济结构失衡密切相关。

# **第六章：两种“杠杆”的辨析**

理解了上述逻辑后，我们再来讨论“杠杆”这个热门词汇。在讨论时，必须清晰地区分两个概念：一个是宏观经济的杠杆率，另一个是金融市场中的杠杆交易。许多人将两者混为一谈，导致了错误的结论。

## **6.1 宏观杠杆率：高储蓄下的必然结果**

宏观经济的杠杆率，实际上指的就是宏观债务率。左边的图表显示了中国非金融部门（企业、居民、政府）的总债务占GDP的比重。目前，这一比率已达到约280%，甚至高于发达国家的平均水平，并且自次贷危机后呈现出非常明显的上升趋势。

许多人因此担忧中国债务过高，会爆发债务危机，并主张“去杠杆”。但只看债务是片面的。我们再看右边的图表，这是中国与其他国家的储蓄率对比。中国的储蓄率即便有所下降，目前仍高达43%左右，而世界其他国家的平均储蓄率仅为22%。

如果你只看到中国的债务比别国多，是否也看到了中国的储蓄比别国多得多呢？简单地从“债务多就必然会爆发危机，所以要去杠杆”这个逻辑出发，是过于简单化且不正确的。

然而，确实有不少人基于这种简单粗暴的逻辑，得出中国需要去杠杆的结论。而宏观去杠杆政策，最终一定会落脚到对社会融资规模（社融）增长的约束上。因为社融增量中超过90%都是债权融资，抑制债务增量必然要抑制社融。

过去几年，只要我们在推行去杠杆政策，首先体现出来的就是社融增长的放缓。社融是实体经济从金融体系获得的融资总量，社融放缓，实体经济的融资需求就得不到满足，有效需求就会收缩，经济增长随之减速。

因此，我们必须认识到：**在中国这样一个储蓄过剩、并由此形成债权融资主导结构的经济体中，国内债务规模的不断上升是合理且必然的。**

如果我们不能接受这一局面，强行推行宏观去杠杆政策，就如同我们在之前模型中讲到的，在价格不能灵活调整的情况下强行减少货币供给，实体经济必然会陷入需求不足的困境。这种政策非但不能引导中国经济走上消费引领的新路（这需要通过调节收入分配来实现），反而在不调节收入分配的前提下，人为地抑制了储蓄向投资的顺畅流动，其结果是引发有效需求不足、经济增长减速和经济低迷，更容易让中国经济滑向长期通缩的“下策”。

所以，宏观的杠杆，不应该去。

## **6.2 金融杠杆交易：需要警惕的顺周期风险**

与宏观杠杆率不同，金融市场中的杠杆交易确实存在巨大风险，政策上需要加以控制。

所谓杠杆交易，简单说就是投资者通过借入资金来放大自己对某类资产的持有量，从而将自己更多地暴露在该资产价格变化的风险之中。杠杆交易会显著放大投资者的盈亏：资产价格上涨时赚得更多，下跌时也亏得更多。

关键在于，杠杆交易中，资产价值的波动性远大于负债价值的波动性。例如，通过券商“两融”业务借钱买股票，借入的资金价值是相对稳定的，但股票价格波动巨大。这会导致投资者的净资产产生巨大波动。

当然，杠杆交易不应一概而论。有时，它是用来对冲风险的，即“套期保值”。比如农场主为对冲未来粮食价格下跌的风险，可以卖出粮食期货。在这种情况下，期货头寸的亏损（或盈利）与他手中现货的盈利（或亏损）相互抵消，杠杆交易反而降低了其总资产的风险。

但更多时候，杠杆交易被用于投机，即单纯地赌未来价格的涨跌。这种情况下，杠杆交易会急剧放大投资者总资产的波动性。

杠杆交易的内在风险在于其**顺周期性**，它容易放大市场波动。

* **上涨周期：** 资产价格上涨 -> 杠杆交易者净资产增加 -> 借贷能力增强 -> 借入更多资金买入资产 -> 进一步推高资产价格。这是一个自我强化的循环。
* **下跌周期：** 资产价格下跌 -> 杠杆交易者净资产缩水 -> 借贷能力下降，甚至触发强制平仓（被要求补充保证金或被强行卖出资产还债） -> 抛售行为进一步打压资产价格 -> 导致更多杠杆交易者需要减仓。这同样是一个自我强化的恶性循环。

这种顺周期性会让市场涨的时候更猛，跌的时候也更急。中国近年来多次经历过杠杆交易引发的剧烈市场波动：

1.  **2015年股灾：** 股市融资余额在一年内从4000多亿激增至2.2万亿，在上涨阶段形成了正向循环。泡沫破灭后，股价下跌引发了融资盘的强制平仓，形成了“踩踏式下跌”，其下跌速度远超以往熊市。
2.  **2016年下半年债市异常波动：** 投资者通过短期回购资金“借短买长”，推高了长期债券价格。当央行收紧短期流动性后，引发了债券的集中抛售，形成了债市的“去杠杆”和踩踏。
3.  **2015年“811”汇改后的人民币贬值：** 此前在人民币升值预期下累积了大量外汇负债的企业，在汇率逆转后争相购汇还债，加剧了人民币的贬值压力，这也是一种杠杆效应。
4.  **近期案例：** 2024年春节前的股市急跌，以及此前理财产品净值的大幅回撤，背后都有杠杆资金踩踏的影子。

这些事件，特别是2015年股灾，曾严重冲击了金融体系的稳定。因此，对于金融杠杆交易，毫无疑问应该保持警惕和控制。

然而，许多不严谨的人正是将这两者混为一谈。他们的逻辑是：你看股灾就是杠杆风险爆发，搞出了这么大的事，那么实体经济的杠杆风险爆发岂不是问题更大？所以实体经济也必须去杠杆。

这就是利用了自然语言的模糊性，进行了概念偷换。这种看似有理的逻辑，其实充满了无法跨越的漏洞，而没有受过严格训练的人很难察觉到这一点。
